САЙТ-ПОДАРОК ДЛЯ ANDREY

1. Открой index.html в браузере, чтобы посмотреть сайт локально.
2. Замени шаблонные тексты на ваши настоящие истории:
   - раздел «Наша история»
   - письмо
   - причины, почему ты его ценишь
   - смешные моменты
   - вопросы викторины
   Ищи эти тексты прямо в index.html через Ctrl+F.
3. Фото:
   - положи изображения в папку assets (например, photo1.jpg)
   - найди блоки <div class="photo"> и замени каждый на:
     <div class="photo"><img src="assets/photo1.jpg" alt="Наш момент"><span>Подпись</span></div>
4. Музыка:
   - используй аудиофайл, который у тебя есть право использовать
   - положи его в assets и назови our-song.mp3
   - сайт уже настроен на этот путь
   - браузеры обычно разрешают музыку только после нажатия на кнопку.
5. Публикация через GitHub Pages:
   - создай аккаунт на github.com, если его ещё нет
   - создай новый публичный репозиторий, например andrey-birthday
   - загрузи index.html и папку assets в корень репозитория
   - открой Settings → Pages
   - в разделе Build and deployment выбери Deploy from a branch
   - Branch: main, folder: /(root), нажми Save
   - подожди публикации; GitHub покажет адрес сайта вида https://ИМЯ.github.io/andrey-birthday/
   - открой ссылку в приватном окне и проверь фото, музыку и кнопки.
Не загружай на сайт личные данные, адреса, пароли или переписки, которые Андрей не хотел бы показывать другим.
